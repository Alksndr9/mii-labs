# ДЗ2. Система правил и промпт-шаблонов

## Проект
**FoodTech MVP** — веб-приложение для заказа готовых рационов здорового питания на 1, 5 или 7 дней: каталог → карточка рациона → корзина → оформление и оплата. Это сквозной проект курса: в ДЗ1 выбран инструмент, в ДЗ3 пишется ТЗ, в ДЗ4–6 — реализация.

## Технологический стек
| Слой | Технологии |
|---|---|
| Язык | TypeScript (strict) |
| UI | React 19, Tailwind CSS v4, React Router |
| Сборка | Vite |
| Тесты | Vitest, React Testing Library |
| Бэкенд | Supabase (PostgreSQL, Auth, Row Level Security) |
| CI/CD и хостинг | GitHub Actions, GitHub Pages |
| AI-агент | Claude Code (выбран в ДЗ1) |

## Ключевые требования к коду
- **Стиль:** функциональные компоненты, именованные экспорты, строгая типизация без `any`, тексты интерфейса на русском.
- **Архитектура:** разбиение по фичам (`src/features/<feature>`), общий код в `src/shared`; доступ к данным только через слой `api/`.
- **Деньги:** целые копейки, форматирование через `Intl.NumberFormat`.
- **Качество:** у каждого компонента с данными — состояния загрузки, ошибки и успеха; у логики — тесты рядом с кодом.
- **Безопасность:** секреты только в переменных окружения, без `dangerouslySetInnerHTML` и SQL-конкатенации.
