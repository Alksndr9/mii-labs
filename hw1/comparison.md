# Сравнительная таблица AI-агентов для разработки

**Задача:** MVP веб-приложения для заказа здорового питания (FoodTech), стек React + TypeScript + Supabase.
Требования к задаче описаны в [report.md](report.md#1-задача-и-требования).

## Типы агентов

| Тип | Где работает агент | Где лежит код | Рассмотрены |
|---|---|---|---|
| **Cloud-агент** | в браузере, на серверах платформы | в облачной песочнице платформы | Bolt.new, Lovable |
| **IDE/CLI-агент** | в редакторе или терминале на компьютере разработчика | локально, в репозитории | Claude Code, Gemini CLI |

Cloud-агенты позволяют быстро получить прототип с нуля без установки, но не работают с локальным проектом: код живёт на платформе. IDE/CLI-агенты работают прямо с репозиторием, терминалом, тестами и git на машине разработчика. В модель уходит только тот контекст, который агент прочитал.

## Шкала оценок

**1** — плохо / дорого / небезопасно, **5** — отлично / бесплатно / безопасно.

## Сводная таблица

| Инструмент | Тип | Контекст проекта | Скорость | Качество кода | Стоимость | Безопасность данных | Интеграция | **Итого** |
|---|---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| Bolt.new | Cloud | 2 | 5 | 3 | 3 | 2 | 2 | **17** |
| Lovable | Cloud | 2 | 5 | 3 | 3 | 2 | 3 | **18** |
| Claude Code | CLI | 5 | 4 | 5 | 3 | 4 | 5 | **26** |
| Gemini CLI | CLI | 4 | 4 | 4 | 5 | 3 | 4 | **24** |

## Обоснование оценок

### Bolt.new (Cloud)
- **Контекст — 2:** видит только проект в своей браузерной песочнице, доступа к локальному репозиторию нет.
- **Скорость — 5:** работающий прототип в браузере за 1–2 минуты, без установки.
- **Качество — 3:** для прототипа достаточно, но код монолитный, мало типизации, нет тестов; на сложной логике агент ходит по кругу.
- **Стоимость — 3:** бесплатного лимита токенов хватает на эксперименты, для реального проекта нужен платный тариф.
- **Безопасность — 2:** код и секреты хранятся на серверах платформы, контроля над данными нет.
- **Интеграция — 2:** работает отдельно от IDE; экспорт в GitHub есть, но вести разработку параллельно локально неудобно.

### Lovable (Cloud)
- **Контекст — 2:** как и Bolt, видит только свой облачный проект.
- **Скорость — 5:** очень быстро генерирует UI по текстовому описанию.
- **Качество — 3:** аккуратный React + Tailwind + shadcn/ui, но поверхностная архитектура и обработка ошибок.
- **Стоимость — 3:** ежедневные бесплатные кредиты, для постоянной работы нужна подписка.
- **Безопасность — 2:** код на стороне платформы; встроенная интеграция с Supabase удобна, но ключи и схема БД проходят через платформу.
- **Интеграция — 3:** двусторонняя синхронизация с GitHub лучше, чем у Bolt, но основная работа всё равно идёт в веб-интерфейсе.

### Claude Code (CLI)
- **Контекст — 5:** работает прямо в репозитории: читает и правит файлы, запускает команды, тесты и git; правила проекта задаются в `CLAUDE.md`.
- **Скорость — 4:** отвечает быстро, но на больших задачах выполняет много шагов (чтение → правка → проверка).
- **Качество — 5:** сильные модели Claude; агент сам проверяет результат (тесты, сборка) и исправляет ошибки.
- **Стоимость — 3:** нужна подписка Claude Pro (около $20 в месяц) или оплата API.
- **Безопасность — 4:** код хранится локально; команды и правки требуют подтверждения; контекст отправляется в API Anthropic.
- **Интеграция — 5:** работает в любом терминале и с любым редактором, расширения для VS Code и JetBrains, поддержка MCP, хуков и запуска в CI.

### Gemini CLI (CLI)
- **Контекст — 4:** работает в локальном репозитории, большое контекстное окно, но в крупных проектах ориентируется хуже Claude Code.
- **Скорость — 4:** быстрые ответы, но иногда упирается в лимиты бесплатного тарифа.
- **Качество — 4:** хороший код для типовых задач, на сложных многошаговых задачах ошибается чаще.
- **Стоимость — 5:** бесплатно с личным Google-аккаунтом (около 1000 запросов в день).
- **Безопасность — 3:** на бесплатном тарифе запросы могут использоваться для улучшения продуктов Google.
- **Интеграция — 4:** open source, поддерживает MCP и интеграцию с VS Code, но экосистема моложе.

## Дополнительный фактор: доступность из РФ

Все четыре инструмента — зарубежные сервисы: для работы из России нужны VPN и зарубежная карта для оплаты. Для проектов с персональными данными (152-ФЗ) или закрытым кодом стоит рассматривать российские решения (GigaCode, YandexGPT) или open-source модели (Qwen, DeepSeek), развёрнутые в контуре компании (on-premise). Для учебного MVP это не критично, но в коммерческом проекте может стать решающим фактором.

> Цены и лимиты указаны ориентировочно на момент выполнения работы; актуальные значения — на официальных страницах тарифов.
